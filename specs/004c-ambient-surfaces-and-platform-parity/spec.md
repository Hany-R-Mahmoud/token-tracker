# Feature Specification: Ambient Surfaces And Platform Parity

**Feature Branch**: `004c-ambient-surfaces-and-platform-parity`  
**Created**: 2026-04-03  
**Status**: Draft

## Goal

Close the compact-surface and platform-level gaps versus CodexBar and AI Token
Monitor.

## Scope

- merge-icons mode or equivalent richer compact status modes
- stronger compact status density and switchable menubar modes
- widget surface
- platform polish for ambient monitoring behavior

## Requirements

- Add a richer compact-status mode system, including a merged/minimal mode where
  appropriate.
- Improve compact menu bar density without sacrificing readability.
- Add a widget surface if technically feasible in the current macOS wrapper
  architecture.
- Keep the menu bar and widget in sync with live monitoring state.
