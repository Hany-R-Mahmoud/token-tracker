# Research Notes: Monitoring And Glanceable UX

## Why This Phase Exists

Token Tracker is already ahead of the formal roadmap on desktop usability, but
the strongest remaining competitive gaps are in monitoring UX rather than core
data plumbing.

## Comparison Takeaways

### AI Token Monitor

- stronger visual analytics presentation
- more obviously "monitoring" oriented at first glance
- useful inspiration for charting and dashboard hierarchy

### CodexBar

- much stronger menu bar glanceability
- reset windows are treated as a first-class product surface
- broader provider coverage, but provider breadth is intentionally out of scope
  for this phase

## Chosen Strategy

- compete on monitoring UX for already-supported providers
- keep architecture stable
- avoid scope creep into provider expansion or cloud features
- preserve local-first privacy and honesty

## Explicit Non-Goals

- Cursor implementation
- Claude implementation
- cloud sync
- leaderboard or social surfaces
- frontend stack rewrite
